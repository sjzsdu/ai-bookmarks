Custom-chip AI inference — several times faster than GPU, with a generous free tier.

- Supports LLaMA, Mistral, Gemma models
- Generous free tier for daily use
- OpenAI-compatible API

## Pricing & access
Free tier available. Pay-as-you-go per token after that. Global access.
