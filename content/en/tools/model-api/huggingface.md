# Hugging Face

The GitHub of AI — largest open-source model hub where almost every open model lives.

## Strengths
- Hundreds of thousands of open-source models (LLaMA, Mistral, etc.)
- Inference API for direct model calls
- Datasets, Spaces for demos
- Transformers library — load models in one line of Python

## Pricing & access
Model downloads free. Inference API has free tier, then pay-as-you-go. Mostly accessible globally.

## Alternatives
ModelScope (better for Chinese models), Replicate (easier deployment).

## Who it's for
AI researchers and developers looking for open-source models or easy deployment.
