# SiliconFlow

China-based inference platform — easy access to open-source models with CNY billing.

## Strengths
- Direct access from China, no VPN needed
- Supports multiple open-source models (LLaMA, Mistral, etc.)
- Pay-as-you-go in CNY with Chinese payment methods
- Good inference speed

## Pricing & access
Free tier available. Pay-as-you-go per token in CNY. Direct access from China.

## Alternatives
Zhipu Open Platform (GLM models), Tongyi API (Alibaba).

## Who it's for
Chinese developers who want to call open-source models without dealing with VPN.
