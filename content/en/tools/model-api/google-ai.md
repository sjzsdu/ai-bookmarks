# Google AI

Google's AI model platform — Gemini models for developers and Vertex AI for enterprise.

## Strengths
- Gemini 1.5 Pro/Flash with strong multimodal capabilities
- Vertex AI enterprise MLOps platform
- Google Search grounding for real-time info
- Generous free tier

## Pricing & access
Free tier available. Pay-as-you-go per token, Gemini Flash is very cheap.

## Alternatives
OpenAI API (better Chinese), Anthropic API (better safety).

## Who it's for
Developers needing multimodal capabilities, especially those already on Google Cloud.
