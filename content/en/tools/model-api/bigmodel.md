Zhipu's open platform (bigmodel.cn) is the official API home of the GLM family — flash through flagship, plus image, video, and agent capabilities, friendly to new users with free quota.

## Getting started

Register for free credits and run a chat call via the OpenAI-compatible interface; enable multimodal and agents as needed.

## What you can actually do

- Full GLM API lineup: chat, reasoning, multimodal
- Agent and tool-calling capabilities
- OpenAI-compatible endpoints for cheap migration

## Trade-offs and gotchas

Capability gaps between tiers are real — match model to task. Occasional peak-hour throttling. Docs sometimes lag new features.

## Alternatives

DeepSeek for reasoning, SiliconFlow for open-model aggregation, Bailian for enterprise RAG.
