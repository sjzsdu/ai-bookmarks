# Anthropic API

Official API for Claude — known for safety, long-context handling, and strong reasoning.

## Strengths
- Claude 3.5 Sonnet, Claude 3 Opus models
- 200K context window for long documents
- Strong safety alignment — harder to jailbreak
- Solid code generation and reasoning

## Pricing & access
Pay-as-you-go per token, similar to OpenAI pricing. Requires credit card, global access.

## Alternatives
OpenAI API (wider ecosystem), Google AI (Gemini).

## Who it's for
Developers and enterprises needing long-context processing and safe, reliable outputs.
