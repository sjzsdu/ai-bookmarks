# Cursor

An "AI-first" code editor forked from VS Code that embeds the model directly into editing, search and refactoring.

## Strengths
Composer for multi-file edits, AI chat, codebase semantic search, one-click apply.

## Access
Client connects directly in most regions; subscription required for heavier use.

## Who it's for
Developers who want to change codebases conversationally; understands the project better than pure completions.
