# FastGPT

FastGPT is an open-source AI application platform from China. It combines knowledge retrieval, chat, and workflow orchestration in a visual interface and can be self-hosted.

## Strengths
- Document ingestion, chunking, vector search, and knowledge Q&A
- Visual workflows and agent tool orchestration
- Integrations with multiple model providers and custom APIs
- Open-source deployment and team controls

## Pricing & access
The open-source edition is free to self-host. Cloud and enterprise capabilities use paid plans.

## Who it's for
Developers and teams building enterprise knowledge assistants, support bots, or internal AI workflows.
