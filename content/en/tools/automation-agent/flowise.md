# Flowise

LangChain without the code — drag and drop nodes to build AI workflows.

## Strengths
- Visual drag-and-drop LangChain builder
- RAG, agents, and conversation chains — all visual
- Export workflows as APIs
- Open source and self-hostable

## Pricing & access
Open source, free to self-host. Cloud from $9/month.

## Alternatives
Dify (more features), n8n (general automation with AI nodes).

## Who it's for
Product managers and ops people who want LangChain's power without writing Python.
