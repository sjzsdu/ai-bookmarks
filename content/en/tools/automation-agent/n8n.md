n8n is the self-hostable workflow platform: 400+ integration nodes plus the freedom to write code wherever needed — the standard answer for teams that want automation without giving up data sovereignty, with AI agent nodes built in.

## Getting started

Deploy with one Docker command or trial the cloud; start from a webhook-triggered scenario and add AI and code nodes gradually.

## What you can actually do

- 400+ integrations with an HTTP-request escape hatch
- Code nodes in JS/Python for any logic
- AI agent nodes with tools and memory

## Trade-offs and gotchas

Self-hosting means you own upgrades and backups. The fair-code license limits resale. Debugging complex flows is middling.

## Alternatives

Zapier/Make for managed simplicity, Activepieces as open-source kin, UiPath for enterprise RPA.
