# AutoGen

Microsoft's open-source framework where multiple AI agents chat and collaborate to solve tasks.

## Strengths
- Conversational multi-agent collaboration
- Human-in-the-loop — people can join agent conversations
- Customizable agent roles and capabilities
- Code execution and tool calling built in

## Pricing & access
Open source, MIT license. Free for any use.

## Alternatives
CrewAI (role-based orchestration), MetaGPT (software dev focus).

## Who it's for
Researchers and developers exploring the possibilities of multi-agent collaboration.
