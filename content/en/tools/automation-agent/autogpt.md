AutoGPT detonated the 'autonomous agent' idea in 2023: give it a goal and it decomposes tasks, calls tools, and loops until done. The original was famously 'runs but unstable', yet its open-source DNA made it the field's textbook — much of today's agent thinking traces back here. Desktop and cloud editions now make it far easier to start.

## Strengths
- Goal-driven autonomous task decomposition
- Plugin ecosystem and custom tools
- Low-code workflow mode (newer versions)
- Self-host or cloud

## Pricing & access

Free and open; you pay model API costs. Proxy required in China.

## Compared
LangChain (framework), CrewAI (multi-agent); AutoGPT is the single-agent pioneer.

## Bottom line

Its value is learning and hacking, not turnkey productivity.
