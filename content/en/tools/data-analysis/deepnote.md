Deepnote turns Jupyter into Google Docs: multiple people edit, comment on, and run the same analysis while the cloud hosts the environment. The built-in AI writes SQL, fixes bugs, and makes charts. It moves data analysis from personal craft to team sport — that's the value.

## Strengths
- Real-time collaborative notebooks with comments
- AI for SQL/Python generation and debugging
- Hosted environments for Python/SQL/R
- One-click interactive report publishing

## Pricing & access
Free tier; from ~$31/month. Proxy required in China.

## Alternatives
ModelWhale domestically, Kaggle (free, competition-flavored).

## Bottom line
Infrastructure for data-team collaboration; the free tier suits individuals.
