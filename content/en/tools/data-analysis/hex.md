# Hex

A collaborative workspace for data teams. Combines SQL queries, Python code, and visualizations in one place, with AI helping you write code and analyze data. Great for data analysts who need code flexibility but want a visual interface too.

## Strengths
- SQL + Python + visualization in one tool
- AI-assisted code generation
- Real-time collaboration
- Publish as interactive apps

## Pricing & Access
- Free: basic features
- Pro: $25/month
- Credit card accepted
- Requires VPN from China

## Alternatives
- Jupyter Notebook
- Google Colab
- Mode

## Who it's for
Data analysts and engineers who need code-based analysis with collaboration.
