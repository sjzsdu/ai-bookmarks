# Mode

A veteran choice for data analysts. Write SQL queries, then turn results into charts and dashboards. More flexible than pure BI tools, more visual than raw SQL. A solid middle ground for daily data analysis work.

## Strengths
- SQL + Python + R support
- Built-in visualization
- Publish and share results
- Scheduling and automation

## Pricing & Access
- Free: basic features, individual use
- Team: $25/month starting price
- Credit card accepted
- Requires VPN from China

## Alternatives
- Looker
- Metabase
- DBeaver

## Who it's for
Data analysts and business analysts who write SQL daily.
