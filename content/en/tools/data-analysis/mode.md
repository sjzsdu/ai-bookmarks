Mode is the analyst-oriented platform: SQL at the core with Python/R for depth, one-click publishing into subscribable reports — a good balance between analytical freedom and operational delivery.

## Getting started

Connect a warehouse, build a SQL report, parameterize dates for auto-refresh; organize assets in Spaces.

## What you can do with it

- Build parameterized SQL reports where stakeholders pick their own date ranges.
- Follow SQL with Python attribution analysis and publish as a subscribable page.
- Turn recurring metric queries into templates new analysts can reuse.

## Limits and gotchas

Requires SQL fluency. Per-seat pricing — check viewer-seat policy. Visualization customization trails dedicated BI.

## Alternatives

Tableau/Power BI for drag-and-drop BI, Hex/Deepnote for notebooks, Julius for lightweight Q&A.
