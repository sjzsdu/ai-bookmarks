Formula Bot attacks one pain: Excel formulas are hard. Describe the need in plain language ('max value per department in column A') and it writes the formula, explains it, and can even decode formulas others wrote. SQL generation included. LLMs have commoditized this, but the add-in form is genuinely convenient.

## Strengths
- Excel/Sheets formula generation and explanation
- SQL generation
- VBA/Apps Script generation
- Official Excel and Sheets add-ins

## Pricing & access
Free quota; from ~$5.99/month. Proxy required in China.

## Alternatives
WPS AI has built-in formula help; any chatbot can do this too.

## Bottom line
A single-point tool that hits a real pain — shallow but sharp.
