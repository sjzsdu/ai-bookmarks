# Cline

Open-source VS Code AI extension that uses your own API keys to call any model (GPT-4, Claude, local Ollama, etc.). Code processes locally, never passes through third parties. Full privacy control.

## Strengths
- Model freedom: OpenAI, Anthropic, local Ollama, etc.
- File read/write, terminal command execution
- Multi-file editing and refactoring
- Fully open source and auditable

## Pricing
Extension is free, bring your own API key with pay-per-use costs. Install directly from GitHub.

## Alternatives
Continue (similar open-source AI coding extension).

## Who it's for
Privacy-focused developers, engineers wanting to use local models, open source enthusiasts.
