Augment is more useful in an unfamiliar large repository than for a tiny snippet. Map modules and call paths first, then request a narrow change. Long context can still misunderstand architecture, so review migrations and bulk edits normally.

AI coding assistant that claims to understand your entire project's architecture and dependencies, not just the current file. Interesting positioning for developers maintaining large legacy codebases.

## Strengths
- Deep codebase architecture understanding
- Cross-file refactoring suggestions
- Context engine: project-level code relationships
- Supports VS Code and JetBrains

## Pricing
Free tier with limited usage, Pro at $30/month. Works globally but subscription requires international payment.

## Alternatives
No direct equivalent. Tongyi Lingma and CodeGeeX focus more on completion than codebase understanding.

## Who it's for
Senior developers maintaining large codebases, enterprise project teams.
