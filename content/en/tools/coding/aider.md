Aider is the open-source community's workhorse pair programmer: sitting in your terminal, it edits files on request and auto-commits — every AI change lands as a git commit you can revert. Its killer feature is model freedom: GPT, Claude, DeepSeek, or local Ollama models all work, and costs stay fully in your hands.

## Strengths
- Natural-language edits with automatic git commits
- Dozens of supported models including local ones
- Multi-file editing with repo-map understanding
- Test-driven loops: runs tests after changes

## Pricing & access
Free and open source; you cover API costs (domestic models reachable directly). Needs Python.

## Compared
Aider + DeepSeek to save money; Claude Code subscription to save effort.

## Bottom line
The engineer's transparent tool: every token and every file change is visible and controllable.
