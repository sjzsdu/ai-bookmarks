Claude Code is the benchmark for agentic coding: not a completion tool but an engineering agent in your terminal — read the repo, plan, code, run tests, commit, for dozens of consecutive steps. Paired with Claude's long context, its grasp of large codebases is among the best available.

## Strengths
- Agentic execution: plan → code → test → commit
- Whole-repo understanding, strong cross-file refactors
- Terminal CLI plus VS Code/JetBrains integrations
- MCP tooling to connect external systems

## Pricing & access
Included in Claude Pro ($20/mo) or Max with usage caps, or metered via API. Proxy required in China.

## Alternatives
Tongyi Lingma and Trae for direct China access with lighter agentic ability.

## Bottom line
Treat it as a junior engineer who can actually work, not an autocomplete — and learn the permission controls first.
