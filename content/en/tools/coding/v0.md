# v0

Vercel's AI frontend tool that generates usable React components from natural language descriptions. Uses shadcn/ui + Tailwind CSS under the hood. A UI accelerator for frontend developers.

## Strengths
- Generate React/Next.js components from text
- Screenshot-to-code conversion
- Generated code is production-ready
- Preview and iterate

## Pricing
Free tier with limited generations, Pro at $20/month. Works globally but subscription requires international payment.

## Alternatives
FlutterFlow (mobile-focused), InstantDesign AI (Chinese UI tool).

## Who it's for
Frontend developers, designers learning to code, anyone needing quick UI prototypes.
