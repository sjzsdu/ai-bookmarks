Gemini Code Assist's kill feature is the free quota: 180,000 completions and 6,000 chat requests per month — an order of magnitude above rivals — so individuals effectively get Gemini-powered completion for nothing. The enterprise tier adds private-repo grounding and GCP integration.

## Strengths
- Gemini-driven completion and generation
- Code explanation, test and comment generation
- VS Code and JetBrains extensions
- Enterprise: private code sources, GCP linkage

## Pricing & access
Free for individuals; enterprise per-seat. Proxy required in China.

## Compared
GitHub Copilot's free tier is far smaller; Tongyi Lingma is the domestic alternative.

## Bottom line
The best free completion option when budget is zero.
