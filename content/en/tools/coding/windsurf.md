# Windsurf

Codeium's AI IDE, built on VS Code architecture. Combines AI chat, code completion, and multi-file editing in one editor. The free tier gives you more tokens than most competitors.

## Strengths
- AI Cascade: multi-step automation for complex tasks
- Inline editing: select code and modify with natural language
- AI Chat: sidebar conversations with full codebase context
- Supports nearly all programming languages

## Pricing
Free tier with generous monthly tokens, Pro at $15/month for unlimited use. Works globally but subscription requires a Visa/Mastercard.

## Alternatives
Trae (ByteDance, completely free), Tongyi Lingma, CodeGeeX.

## Who it's for
Developers wanting to try AI IDEs without paying upfront, indie developers on a budget.
