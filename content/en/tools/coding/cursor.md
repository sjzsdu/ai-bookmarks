"AI-first" code editor forked from VS Code, embedding models directly into editing, search, and refactoring. Composer can modify multiple files at once — useful for large refactors.

## Strengths
- Composer: multi-file editing and refactoring
- AI Chat: sidebar conversations with codebase context
- Semantic code search in natural language
- One-click apply AI-generated changes

## Pricing
Free tier with basic features, Pro at $20/month. Client connects directly in most regions; subscription may require international payment.

## Alternatives
Windsurf (Codeium, more free tokens), Trae (ByteDance, completely free).

## Who it's for
Developers wanting conversational codebase changes; understands projects better than pure completion tools. Check data compliance for sensitive code.
