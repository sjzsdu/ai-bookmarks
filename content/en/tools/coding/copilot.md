# GitHub Copilot

Microsoft's AI code-completion tool built on OpenAI models, deeply integrated with mainstream IDEs. The most widely installed "AI pair programmer" with top-tier completion accuracy.

## Strengths
- Inline completion: write a comment or signature, get the rest
- Whole-function generation from descriptions
- Copilot Chat: in-IDE conversations for explanations, debugging, refactoring
- Terminal command suggestions from natural language

## Pricing
Personal at $10/month, Business at $19/seat. Free for students and some OSS contributors. GitHub is accessible globally, but subscription requires international payment.

## Alternatives
Cursor for AI-native editing, Codeium for free tier, Tongyi Lingma for Chinese teams.

## Who it's for
Engineers writing code daily; free only for students and some OSS contributors.
