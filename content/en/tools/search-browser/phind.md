# Phind

Developer-focused AI search that finds code solutions faster than Googling stack traces.

## Strengths
- Pulls answers from Stack Overflow, GitHub, and official docs
- Code search with syntax highlighting and examples
- Customizable search scope by tech stack
- Pair Programming mode for writing code alongside search

## Pricing & access
Free tier with daily search limits. Pro at $15/month unlocks more searches and advanced models. Global access.

## Alternatives
Devv (dev-focused), Perplexity (general search).

## Who it's for
Developers, DevOps engineers, and technical leads debugging issues or evaluating tech choices.
