Qingyan is the official app from Zhipu AI, a Tsinghua-affiliated company: long-document handling, technical Q&A, and code are solid. The GLM family is free, and AutoGLM adds agent capabilities — simulating human operations across phone and browser to finish multi-step tasks.

## Strengths
- GLM-4 chat, writing, and code
- Long-document upload and Q&A
- AutoGLM agents for phone/browser automation
- Built-in image and video generation

## Pricing & access
Free, direct access; developers can use the BigModel API alongside.

## Compared
DeepSeek (stronger reasoning), Qwen (bigger ecosystem); Qingyan's edge is academic grounding and agents.

## Bottom line
One of the genuinely useful free models, especially for technical work.
