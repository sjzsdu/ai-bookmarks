# Grok

xAI's chat model, deeply integrated with X/Twitter for strong real-time information. Direct, sometimes humorous response style.

## Strengths
- Real-time info (X/Twitter data integration)
- Direct, no-nonsense response style
- Image understanding and generation
- Solid coding and reasoning

## Pricing & access
X Premium+ required for full access (~16 USD/month). Available globally (requires X account).

## Alternatives
ChatGPT (broader features), Claude (better writing), Gemini (search integration).

## Who it's for
X/Twitter power users, those following real-time global news, English content consumers.
