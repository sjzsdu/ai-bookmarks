The overlooked fact about Copilot: it gives you GPT-class models for free. Chat, image generation, and web-grounded answers cost nothing, and Windows 11 ships it in the OS. The consumer tier covers daily use; Microsoft 365 Copilot is the real commercial play — working directly inside Word, Excel, and Outlook.

## Strengths
- GPT-class chat + DALL·E images, free
- Web search with cited sources
- Deep Windows 11 and Edge integration
- M365 Copilot works inside Office documents (enterprise)

## Pricing & access
Consumer free; M365 Copilot $30/user/month. Proxy required in China.

## Compared
Same model lineage as ChatGPT with a different ecosystem; the free tier is slightly richer.

## Bottom line
The default assistant for Microsoft shops; for everyone else, free GPT.
