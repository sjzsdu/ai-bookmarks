ChatGPT earns its keep when you iterate: turn a rough idea into an email, outline, or code draft. It is great for everyday knowledge work; it is not a source of record, so check numbers, citations, and policy claims.

OpenAI's conversational model — the most recognized AI entry point worldwide. Strong at writing, coding, translation, and brainstorming with the most complete feature ecosystem.

## Strengths
- Long-form writing, code generation, data analysis
- Web search (paid), rich plugin ecosystem
- GPT-4o multimodal (image, voice, video understanding)
- Custom GPTs ecosystem

## Pricing & access
Free tier with GPT-4o mini; Plus ~20 USD/month. Available globally; enterprise via Azure OpenAI.

## Alternatives
Claude (better writing), Gemini (search integration), DeepSeek (free, strong Chinese).

## Who it's for
Students, operators, developers, researchers — nearly universal, with cost as the main scaling limit.
