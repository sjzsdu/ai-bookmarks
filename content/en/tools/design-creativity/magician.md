Magician is one of the best-known Figma AI plugins: generate icons, images, and text right on the canvas, with outputs landing as editable layers. It fixes the 'missing asset mid-design' gap.

## Getting started

Run commands on selected layers; for icon sets, reuse the same descriptor root to keep style consistent. Text generation suits UI micro copy.

## What you can actually do

- Icon generation from text descriptions
- Image generation for placeholders and moods
- Copy generation for interface text

## Trade-offs and gotchas

Built by Diagram, now acquired by Figma — integration pacing shifts. Verify image rights per platform terms before publishing.

## Alternatives

Figma's native AI is catching up, Uizard for prototype-to-code, Motiff's plugins in the domestic ecosystem.
