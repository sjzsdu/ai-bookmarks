Uizard fixes 'the idea is in my head but I can't draw it': photograph a hand-drawn wireframe into an interactive prototype, or generate full app screens from one description. Output is for communication and validation, not shipping.

## Getting started

Use Autodesigner with a product description for v1, then adjust theme and layout in the editor. Sketch scanning tolerates rough wireframes — whiteboard photos work.

## What you can actually do

- Sketch-to-prototype: wireframes to clickable UI
- Text-to-design: descriptions to multi-screen apps
- Theme transfer: one-click restyling

## Trade-offs and gotchas

Screens are demo-grade, not design-system compliant; code export is limited, so handoff still needs designers and engineers.

## Alternatives

Figma AI for professional flows, Motiff for domestic teams, v0 or Lovable for shippable code.
