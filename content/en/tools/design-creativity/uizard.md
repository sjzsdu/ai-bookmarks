# Uizard

AI UI design tool that turns hand-drawn sketches or screenshots into interactive prototypes. A shortcut for non-designers to create UI prototypes without learning Figma.

## Strengths
- Sketch-to-UI conversion
- Screenshot-to-editable design
- AI theme generation
- Drag-and-drop editor

## Pricing
Free tier with 3 projects, Pro at $12/month. Accessible globally.

## Alternatives
InstantDesign (Chinese UI design tool), Modao (Chinese prototyping tool).

## Who it's for
Product managers, non-designers, anyone needing quick UI prototypes to validate ideas.
