# Flux

Black Forest Labs 推出的开源文生图模型（FLUX.1 系列），在开放权重模型里画质天花板级别，提示词还原非常准。

## 核心能力
- 文生图细节丰富，文字渲染能力比大多数开源模型强
- 支持多种变体（dev / schnell / pro），速度与质量可选
- ComfyUI / WebUI 生态支持好，LoRA 等微调可用

## 价格与访问
完全开源免费，本地部署仅需显卡成本。也可通过 Replicate、fal.ai 等云端 API 按量付费使用。

## 国内替代
Stable Diffusion（生态更成熟）、通义万相（在线直连）、可灵图像（国内直连）。

## 适用人群
有显卡资源、追求高画质开源方案的设计师与开发者。
