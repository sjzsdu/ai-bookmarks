GPT Image 是 OpenAI 的旗舰图像生成与编辑能力，可理解复杂指令、在画面中渲染文字，并在对话中根据反馈持续修改图片。

## 核心能力
- 文生图和参考图编辑
- 多轮自然语言修改
- 海报、标识等场景的文字渲染
- 通过 ChatGPT 和 API 使用

## 价格与访问
ChatGPT 用户可按套餐使用一定额度，开发者 API 按生成规格和用量计费。可用地区以 OpenAI 政策为准。

## 适用人群
营销团队、设计师、内容创作者和需要集成图像生成能力的开发者。
