# GitHub Copilot

微软出品的 AI 编程补全工具，基于 OpenAI 模型，深度集成主流 IDE，是开发者最普及的「AI 结对程序员」。

## 国内要点
- GitHub 与 Copilot 国内通常可直连，但订阅需境外信用卡。
- 企业版支持私有代码合规策略，数据不外泄训练。

## 核心能力
行内补全、整函数生成、聊天问答（Copilot Chat）、终端命令建议。

## 国内替代
通义灵码、CodeGeeX、百度 Comate 等国产方案，中文注释理解与本地部署更友好。

## 适用人群
日常写代码的工程师；免费额度仅给学生与部分开源贡献者。
