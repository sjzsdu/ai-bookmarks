CSM 是图生 3D 领域的早期探索者，如今的定位是「给开发者用的 3D 生成 API」：电商想让商品照片变 3D 展示、教育平台想让学生上传草图生成模型，接 CSM 的 API 就行。Web 端也能手动用，但它的真正价值在管线集成。

## 核心能力
- 图像/草图转 3D API
- 实时预览生成
- 多格式导出与 PBR 贴图
- 批量处理管线

## 价格与访问
免费额度；按量计费。需代理。

## 国内替代
混元 3D 也提供 API 且免费额度大；国内集成优先看混元。

## 定位
3D 生成的基础设施供应商。
