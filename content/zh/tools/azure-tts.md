# 微软 Azure TTS

微软认知服务中的语音合成，提供多语种神经语音，企业级稳定与可定制。

## 为什么国内企业选它
- Azure 中国由世纪互联运营，可合规境内调用、人民币结算。
- 神经语音自然，支持自定义音色（需申请）。
- 有 SLA 与海量并发，适合生产环境。

## 核心能力
多语种 TTS、情感语音、实时/批量合成、SSML 精细控制。

## 适用人群
需要稳定语音输出的 App、客服、导航、有声内容平台。
