# Lingvanex

小众但功能全面的翻译 API 服务。支持 100+ 语言，有云端和本地部署两种方式。适合需要批量翻译、不想依赖大厂 API 的开发者。

## 核心能力
- 100+ 语言支持
- 提供 REST API 和 SDK
- 支持本地部署（离线翻译）
- 文本、语音、图片翻译

## 价格与访问
- 免费版：5000 字符/月
- 基础版：$10/月，50 万字符
- 支持信用卡付款
- 国内访问可能较慢

## 国内替代
- 百度翻译 API
- 腾讯翻译 API
- 阿里翻译 API

## 适用人群
需要批量翻译的开发者，对隐私有要求需要本地部署的团队。
