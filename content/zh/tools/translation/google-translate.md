# Google Translate

覆盖面最广的免费翻译服务。支持 130+ 语言，虽然单句翻译质量不如 DeepL，但胜在免费、速度快、语种全。拍照翻译和语音翻译功能在出国时特别实用。

## 核心能力
- 130+ 语言互译，语种覆盖最全
- 拍照翻译、语音翻译、手写识别
- 网页版、App、API 都有
- 支持离线翻译包下载

## 价格与访问
- 完全免费
- API 调用有免费额度，超出后按字符计费
- 国内需要翻墙使用

## 国内替代
- 腾讯翻译君
- 百度翻译
- 有道翻译

## 适用人群
需要翻译小语种、出国旅行、快速理解外文内容的用户。
