AutoGPT 是 2023 年引爆「自主 Agent」概念的项目：给它一个目标，它自己拆任务、调工具、循环执行。原始版本以「能跑但不稳」著称，但它的开源基因让它成为 Agent 领域的教科书——今天大量的 Agent 框架思想都源自这里。现在有桌面版和云服务，上手容易了很多。

## 核心能力
- 目标驱动的自主任务拆解与执行
- 插件生态与自定义工具
- 低代码工作流模式（新版本）
- 自托管与云托管双形态

## 价格与访问
开源免费；模型 API 费自付。需代理。

## 同类对比
LangChain（框架向）、CrewAI（多 Agent）；AutoGPT 是单 Agent 自主执行的鼻祖。

## 定位
价值在学习和改造，不在直接生产力。
