# Flowise

LangChain的可视化版本，拖拽节点就能搭AI工作流，不用写一行代码。

## 核心能力
- 拖拽式LangChain工作流搭建
- RAG知识库、Agent、对话链都可以搭
- 支持导出为API
- 开源可自托管

## 价格与访问
开源免费自托管。Cloud版9美元/月起。
