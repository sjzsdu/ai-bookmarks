# n8n

开源的工作流自动化工具，用节点把不同系统连起来，也能把大模型塞进自动化流程。

## 核心能力
- 可视化自动化，400+集成节点
- HTTP/数据库/AI节点，灵活组合
- 定时与事件触发
- 开源可自托管，数据留在自己服务器

## 价格与访问
开源免费自托管。Cloud版按量付费，欧元计价。

## 国内替代
Huginn（开源）、Activepieces（开源自动化）。

## 适用人群
想把AI嵌入内部流程的运营、IT、开发者。
