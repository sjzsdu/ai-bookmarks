n8n 是可自托管的工作流自动化平台：400+ 集成节点加「随时可以写代码」的灵活性，让它成为既要自动化又在意数据主权团队的标准答案，AI Agent 节点也让大模型能力直接进管线。

## 上手体验

Docker 一行命令自部署，或先用云版试用；从 Webhook 触发的简单场景开始，逐步加 AI 和代码节点。

## 具体能干嘛

- 400+ 集成节点加 HTTP 请求节点兜底
- 代码节点：JS/Python 处理任意逻辑
- AI Agent 节点：工具调用和记忆内建

## 不足和坑

自部署要自己负责升级和数据备份；fair-code 协议对商业转售有限制；复杂流程的调试体验一般。

## 替代方案

托管省心用 Zapier/Make；开源同类看 Activepieces；企业 RPA 场景用 UiPath。
