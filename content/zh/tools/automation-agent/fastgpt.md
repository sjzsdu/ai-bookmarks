# FastGPT

FastGPT 是国产开源的 AI 应用平台，将知识库检索、对话和工作流编排集中在可视化界面中，既能快速搭建原型，也支持自托管。

## 核心能力
- 文档导入、分段、向量检索和知识库问答
- 可视化工作流与 Agent 工具编排
- 支持接入多家大模型与自定义 API
- 开源部署和团队权限管理

## 价格与访问
开源版本可免费自托管，云服务和企业能力按方案收费。

## 适用人群
需要搭建企业知识助手、客服机器人或内部 AI 工作流的开发者和团队。
