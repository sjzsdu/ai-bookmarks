# AutoGen

微软开源的多Agent对话框架，让多个AI代理通过对话协作完成任务。

## 核心能力
- 多Agent对话式协作
- 支持人机协作，人类可以介入Agent对话
- 可自定义Agent角色和能力
- 支持代码执行和工具调用

## 价格与访问
完全开源免费，MIT协议。

## 国内替代
CrewAI（更注重角色分工）、MetaGPT（软件开发场景）。

## 适用人群
研究者和开发者，想探索多Agent协作的各种可能性。
