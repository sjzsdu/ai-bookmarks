UiPath 是 RPA（机器人流程自动化）这门生意的定义者：让软件机器人模拟人在电脑上的操作——点按钮、填表单、跨系统搬数据。当流程涉及没有 API 的老旧系统时，RPA 是唯一解。近年它把大模型接进来做文档理解和决策，老树发新芽。

## 核心能力
- 桌面级 RPA：模拟人工操作任意软件
- Document Understanding：发票、表单智能识别
- AI Center：模型接入自动化编排
- 企业级治理、审计与调度

## 价格与访问
社区版免费；企业版按需定价。需代理。

## 国内替代
影刀 RPA、来也 UiBot——本土合规和价格优势明显。

## 定位
企业自动化的重型装备，个人玩家看看社区版就好。
