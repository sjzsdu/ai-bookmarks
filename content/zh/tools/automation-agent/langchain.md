# LangChain

AI应用开发的标准框架，把LLM、数据库、API串在一起构建复杂应用。

## 核心能力
- 链式调用（Chain）编排复杂逻辑
- Agent可以让LLM自己决定调用什么工具
- RAG知识库集成
- 支持Python和JavaScript

## 价格与访问
完全开源免费。LangSmith监控平台有免费额度，超出按量付费。

## 国内替代
Dify（可视化版LangChain）、LlamaIndex（文档处理更强）。

## 适用人群
想构建复杂AI应用的开发者，需要一定编程基础。
