# Dify

开源的LLM应用开发平台，把RAG、Agent、工作流、模型路由整合到可视化界面。

## 核心能力
- Prompt编排、RAG知识库、Agent
- 可视化工作流，从原型到生产
- 模型路由，一个平台接多个大模型
- 开源可自托管，数据自主

## 价格与访问
开源免费自托管。Cloud版按量付费。中文文档和社区活跃。

## 国内替代
扣子（coze.cn）——零代码更快。FastGPT——知识库场景更强。

## 适用人群
想自建AI应用/知识库的企业与开发者。
