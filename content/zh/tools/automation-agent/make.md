# Make

可视化自动化平台，用流程图的方式搭工作流，比Zapier灵活很多。

## 核心能力
- 流程图式可视化编辑，逻辑清晰
- 支持复杂分支、循环、错误处理
- AI模块可以调用各种大模型
- 价格比Zapier便宜

## 价格与访问
免费版每月1000次操作。9美元/月起步。全球可用。

## 国内替代
n8n（自托管）、Huginn（开源）。

## 适用人群
需要复杂工作流、在意性价比的自动化爱好者。
