# 扣子（Coze）

字节推出的零代码AI智能体平台，拖拽即可搭建Bot并发布到多个渠道。

## 核心能力
- Bot编排、插件市场、知识库、工作流
- 国内直连，豆包模型，中文生态好
- 多渠道发布：微信公众号、飞书、网页
- 上手快，非技术同学也能用

## 价格与访问
完全免费，国内直连，不需要VPN。手机号注册。
