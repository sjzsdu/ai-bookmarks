Langflow 用节点和连线表达 LLM 应用逻辑，让开发者直观看到模型、提示词、检索器、记忆和工具之间的数据流，并快速测试 Agent 或 RAG 原型。

## 核心能力
- 拖拽式可视化流程编辑器
- 连接主流模型、向量库和外部工具
- Agent、RAG 和多步骤链路编排
- 开源自托管与可扩展组件

## 价格与访问
开源版本可免费使用和自托管，托管云服务按官方方案收费。

## 适用人群
需要快速验证 LLM 工作流，同时希望保留代码扩展能力的开发者和 AI 团队。
