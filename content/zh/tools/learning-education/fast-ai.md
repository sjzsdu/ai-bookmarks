fast.ai（课程与开源库）是深度学习教育里口碑最好的免费资源之一：Jeremy Howard 的「自上而下」教学让你第一节课就训练出图像分类器，理论随后补齐，配套 fastai 库工程质量极高。

## 上手体验

从「Practical Deep Learning for Coders」第一课开始，跟着 notebook 在 Colab 或本地跑通；库的文档和论坛都是学习材料。

## 具体能干嘛

- 跟第一课在 Colab 上训练出第一个图像分类器，再回头理解原理。
- 用 fastai 库的数据块 API 快速处理自己的数据集。
- 在论坛对照他人方案，学习生产级的训练技巧。

## 不足和坑

需要 Python 基础；自上而下教学不适合每个人；课程内容迭代后部分资料对应旧版本。

## 替代方案

系统理论课看 Coursera 的专项；论文工具用 Elicit；数学直觉用 Brilliant。
