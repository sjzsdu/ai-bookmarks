# Claude

Anthropic 开发的对话模型，以「更安全、更长上下文、写作更自然」为卖点，Artifacts 功能便于做可交互原型。

## 国内使用要点
- 官网访问同样需要代理。
- 合规企业可通过 AWS Bedrock 或 Azure 调用 Claude 系列模型，避免直连风险。

## 核心能力
支持超长上下文（最高 200K+ token），适合整本 PDF、代码库级别的理解；写作逻辑严密。

## 与 ChatGPT 的区别
更克制、更少胡说，长文本任务占优；但中文语料与本地化生态弱于国产模型。

## 适用人群
重度写作、法律/金融研报、长代码库维护者。
