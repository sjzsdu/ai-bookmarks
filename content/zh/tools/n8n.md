# n8n

开源的工作流自动化工具，用节点把不同系统连起来，也能把大模型塞进自动化流程。

## 为什么用自托管
- 数据留在本机/自有服务器，合规可控。
- 节点丰富，接数据库、SaaS、Webhook 都很方便。
- 可与 Dify/Coze 的 API 组合，做「AI + 业务」闭环。

## 核心能力
可视化自动化、HTTP/数据库节点、AI 节点、定时与事件触发。

## 适用人群
想把 AI 嵌入内部流程的运营、IT、开发者。
