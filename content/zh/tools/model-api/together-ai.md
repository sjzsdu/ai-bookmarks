# Together AI

专注开源模型的推理平台，LLaMA、Mistral等模型调用速度快、价格低。

## 核心能力
- 主流开源模型都有（LLaMA 3、Mistral等）
- 推理速度快，价格比OpenAI便宜
- 支持微调和自定义模型部署
- Embedding服务也有

## 价格与访问
按Token计费，开源模型价格很低。需要VPN。

## 国内替代
硅基流动（siliconflow.cn）——国内直连，类似定位。

## 适用人群
想用便宜、快速调用开源模型的开发者。
