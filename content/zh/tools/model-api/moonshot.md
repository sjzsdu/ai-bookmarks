Moonshot 开放平台是 Kimi 背后的开发者服务，提供面向对话、长文本处理和推理场景的大模型 API，适合构建中文 AI 应用。

## 核心能力
- 长上下文文本理解与生成
- 对话、结构化输出和工具调用
- 面向开发者的 API 控制台与用量管理
- 对中文知识和应用场景支持良好

## 价格与访问
国内可访问，通常按模型和 Token 用量计费。模型列表、上下文长度与单价以开放平台为准。

## 适用人群
构建智能客服、知识助手、内容处理和 Agent 应用的国内开发者与企业。
