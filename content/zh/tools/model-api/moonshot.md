月之暗面（Moonshot）的开放平台提供 Kimi 系列模型 API：长文本理解是招牌，配合工具调用和联网检索能力，OpenAI 兼容接口接入成本低。

## 上手体验

注册后用 OpenAI 兼容 SDK 接入；长文档场景先测上下文窗口和价格再上量。

## 具体能干嘛

- Kimi 模型 API：长上下文对话与推理
- 工具调用：函数调用标准支持
- 联网检索：内置搜索增强问答

## 不足和坑

长文本按 token 计费成本可观，注意分段策略；模型更新后行为可能变化；多模态能力相对有限。

## 替代方案

长文本对比 DeepSeek/Anthropic；多模态用 Gemini；聚合接入用 OpenRouter。
