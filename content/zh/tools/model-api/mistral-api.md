Mistral 是欧洲 AI 的代表厂商，API 平台的卖点是「够用且便宜」：旗舰模型比肩国际二线，小模型（Ministral 系列）效率极高，Codestral 代码模型在补全场景口碑很好。对欧洲业务，数据不出欧洲的合规性是硬需求。

## 核心能力
- Mistral Large/Small 全系模型
- Codestral 代码专用模型
- 免费实验档
- 欧洲数据合规（GDPR）

## 价格与访问
按量付费，价格低于同级美系厂商。需代理。

## 同类对比
DeepSeek（更便宜更强推理）、Mistral（欧洲合规）；中文场景两者都一般。

## 定位
特定合规与性价比生态位上的优秀选择。
