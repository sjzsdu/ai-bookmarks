# 智谱 BigModel

BigModel 是智谱面向开发者和企业的大模型开放平台，也是智谱清言背后的模型能力入口。平台覆盖文本、多模态和应用开发所需的常见 API。

## 核心能力
- GLM 系列对话与推理模型
- 图像理解、图像生成等多模态接口
- 向量、知识库和工具调用能力
- 国内控制台、文档和人民币结算

## 价格与访问
部分能力提供体验额度，正式使用按模型和调用量计费。企业还可咨询私有化和定制服务。

## 适用人群
需要国产模型、国内部署支持或中文应用生态的开发者和企业。
