智谱开放平台（bigmodel.cn）是 GLM 系列模型的官方 API 入口：从轻量的 flash 到旗舰模型，加上图像、视频和 Agent 能力，免费档对新用户友好。

## 上手体验

注册领免费额度，用 OpenAI 兼容接口先跑通对话；多模态和 Agent 能力按需开通。

## 具体能干嘛

- GLM 全系模型 API：对话/推理/多模态
- Agent 与工具调用能力
- OpenAI 兼容接口降低迁移成本

## 不足和坑

不同档位模型能力差距明显，按场景选型；高峰期限流偶发；部分新能力文档滞后于功能上线。

## 替代方案

推理优先选 DeepSeek；开源聚合看 SiliconFlow；企业 RAG 平台看百炼。
