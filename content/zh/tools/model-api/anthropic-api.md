# Anthropic API

Claude系列模型的官方API，以安全性和200K上下文窗口著称。

## 核心能力
- Claude 3.5 Sonnet、Claude 3 Opus等模型
- 200K上下文窗口，处理长文本很强
- 安全策略好，不容易被jailbreak
- 代码能力和推理能力都不错

## 价格与访问
按Token计费，价格和OpenAI差不多。需要信用卡和VPN。

## 国内替代
硅基流动（siliconflow.cn）——支持部分Claude模型。通义千问——长文本能力也不错。

## 适用人群
需要处理长文档、重视输出安全性的开发者和企业。
