硅基流动（SiliconFlow）是国内的开源模型推理聚合平台：DeepSeek、Qwen、GLM 等主流开源模型一个 API 全覆盖，价格常比官方平台更低，是国内开发者的常用底座。

## 上手体验

注册后用 OpenAI 兼容接口接入，先在小模型上验证链路再切主力模型；关注免费额度和促销。

## 具体能干嘛

- 多模型一站调用：DeepSeek/Qwen/GLM 等
- OpenAI 兼容接口，迁移成本低
- 国内直连，人民币结算

## 不足和坑

托管模型的版本和量化方式可能与官方不同，效果有差异；高峰期限流明显；关键业务建议双供应商兜底。

## 替代方案

官方原厂 API 看 DeepSeek/百炼/方舟；聚合海外模型用 OpenRouter；本地部署用 Ollama。
