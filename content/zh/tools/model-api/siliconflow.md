# 硅基流动

国内做得比较好的AI推理平台，开源模型调用方便，按量人民币付费。

## 核心能力
- 国内直连，不需要VPN
- 支持多种开源模型（LLaMA、Mistral等）
- 按量付费，人民币结算
- 推理速度不错

## 价格与访问
有免费额度。超出后按Token计费，人民币支付，国内银行卡即可。
