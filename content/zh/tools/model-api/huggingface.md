# Hugging Face

AI界的GitHub，最大的开源模型库，几乎所有开源模型都能在这找到。

## 核心能力
- 数十万个开源模型（LLaMA、Mistral等）
- Inference API直接调用模型
- Datasets数据集、Spaces演示空间
- Transformers库，Python一行代码加载模型

## 价格与访问
模型下载免费。Inference API有免费额度，超出按量付费。基本国内可访问。

## 国内替代
ModelScope（魔搭）——阿里出品，国内模型更全。百度飞桨——PaddlePaddle生态。

## 适用人群
AI研究者、开发者，想找开源模型或部署模型的人。
