OpenRouter 解决的是「模型太多，账户太乱」：一个 API key、一套 OpenAI 兼容接口，调用 OpenAI、Anthropic、Google、Meta 以及各种开源模型，300+ 可选。带自动故障转移——主力模型挂了自动切备用。对需要多模型的开发者，它是省心程度最高的方案。

## 核心能力
- 300+ 模型统一 OpenAI 兼容接口
- 自动故障转移与负载路由
- 用量分析和成本统计
- 部分开源模型免费档

## 价格与访问
模型原价 + 约 5% 服务费。需代理。

## 同类对比
SiliconFlow（国产聚合）、Together（开源向）；全球覆盖 OpenRouter 最全。

## 定位
多模型开发者的瑞士军刀。
