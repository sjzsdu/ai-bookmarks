# OpenAI API

GPT系列模型的官方API，按Token计费，应用最广泛。

## 核心能力
- GPT-4o、GPT-4、GPT-3.5等模型
- 图片生成（DALL·E）、语音（Whisper）
- Embedding、微调、Assistants API
- 文档和社区最完善

## 价格与访问
按Token计费，不同模型价格不同。注册需要信用卡。国内访问需要VPN或中转。

## 国内替代
硅基流动（siliconflow.cn）——国内直连，支持多种模型。通义千问API——阿里出品。

## 适用人群
开发者、企业，需要调用大模型API构建应用。
