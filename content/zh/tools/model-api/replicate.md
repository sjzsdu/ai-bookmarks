# Replicate

把开源模型变成API的服务，不用自己买GPU、配环境。

## 核心能力
- 一键部署开源模型为API
- 自动扩缩容，按使用量付费
- 支持图像、视频、文本等多种模型
- Cog容器，打包和分享模型很方便

## 价格与访问
按GPU使用时间计费，不同模型价格不同。需要VPN。

## 国内替代
硅基流动（siliconflow.cn）——国内直连，按量付费。智谱开放平台。

## 适用人群
想快速用上开源模型但不想管服务器的开发者。
