# GitHub Copilot Workspace

GitHub 官方推出的 AI 开发环境，能从一个 issue 出发，自动分析代码库、制定计划、编写代码、运行测试，最终生成 PR。是目前从问题到代码最完整的 AI 工作流。

## 核心能力
- 从 issue 自动理解需求并制定开发计划
- 多文件代码生成和修改
- 自动运行测试验证
- 一键生成 Pull Request

## 价格与访问
目前包含在 Copilot 订阅中，个人版 10 美元/月。国内可访问 GitHub，但需要外币信用卡订阅。

## 国内替代
暂无直接替代品，国内平台（如 Gitee）尚未推出类似功能。

## 适用人群
重度 GitHub 用户、开源贡献者、想让 AI 处理重复性开发任务的工程师。
