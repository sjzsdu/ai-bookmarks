Claude Code 是「代理式编程」的标杆：它不是一个补全工具，而是一个跑在终端里的工程代理——读代码库、规划任务、写代码、跑测试、提交修改，可以连续执行几十个步骤。搭配 Claude 系列模型的长上下文，它对大型代码库的理解是同类产品里最好的之一。

## 核心能力
- 代理式任务执行：规划 → 改码 → 测试 → 提交
- 整库理解，跨文件重构能力强
- 终端 CLI + VS Code/JetBrains 集成
- 可配置 MCP 工具连接外部系统

## 价格与访问
随 Claude Pro（20 美元/月）或 Max 订阅使用，用量有上限；也可走 API 按量付费。需代理。

## 国内替代
通义灵码（Qwen 驱动、直连）、Trae（字节，界面化）——代理能力稍弱但可直连。

## 适合谁
把它当成「能干活的初级工程师」而不是补全工具，价值最大化；用前先熟悉权限控制。
