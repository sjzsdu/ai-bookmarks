# Cline

开源的 VS Code AI 扩展，你可以用自己的 API Key 调用任何模型（GPT-4、Claude、本地模型等）。代码直接在本地处理，不经过第三方服务器，隐私控制完全在自己手里。

## 核心能力
- 自选模型：支持 OpenAI、Anthropic、本地 Ollama 等
- 文件读写、终端命令执行
- 多文件编辑和重构
- 完全开源，可审计代码

## 价格与访问
扩展免费，需要自己准备 API Key，费用按模型调用量走。国内可直接从 GitHub 下载安装。
