# GitHub Copilot

微软出品的 AI 编程补全工具，基于 OpenAI 模型，深度集成主流 IDE。是目前装机量最大的「AI 结对程序员」，补全准确率在同类产品里算第一梯队。

## 核心能力
- 行内补全：写注释或函数签名，自动补全剩余代码
- 整函数生成：描述需求生成完整函数
- Copilot Chat：IDE 内对话问答，解释代码、调试、重构
- 终端命令建议：用自然语言描述操作，自动生成命令行指令

## 价格与访问
个人版 10 美元/月，企业版 19 美元/席位。学生和部分开源贡献者免费。国内 GitHub 可直连，但订阅需要 Visa/Mastercard。

## 国内替代
通义灵码（阿里出品，免费）、CodeGeeX（智谱出品）、百度 Comate。

## 适用人群
日常写代码的工程师；免费额度仅给学生与部分开源贡献者。
