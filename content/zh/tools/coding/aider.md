Aider 是开源社区的主力 AI 结对编程工具：装在终端里，对着你的 git 仓库说需求，它直接改文件并自动 commit——每一次 AI 修改都有提交记录，不满意就 revert。最大的优势是模型自由：GPT、Claude、DeepSeek、本地 Ollama 模型都能接，成本完全自己掌控。

## 核心能力
- 自然语言修改代码，自动 git 提交
- 支持数十种模型（含本地模型）
- 多文件编辑、repo-map 全库理解
- 可加测试驱动：改完自动跑测试

## 价格与访问
免费开源；API 费用自付（接国产模型可直连）。安装需 Python 环境。

## 同类对比
要省钱选 Aider + DeepSeek，要省心选 Claude Code 订阅。

## 定位
工程师的透明工具：知道自己花了多少 token、改了哪些文件，一切可控。
