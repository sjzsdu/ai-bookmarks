# Windsurf

Codeium 推出的 AI IDE，基于 VS Code 架构，把 AI 对话、代码补全、多文件编辑揉进一个编辑器里。免费版给的 token 额度比同类产品多不少。

## 核心能力
- AI Cascade：多步骤自动完成复杂任务
- 内联编辑：选中代码直接用自然语言修改
- AI Chat：侧边栏对话，可以引用整个代码库上下文
- 支持几乎所有编程语言和主流 IDE 插件

## 价格与访问
免费版每月有较多 token 额度，Pro 版 15 美元/月去掉限制。国内可直连但稳定性一般，订阅需要 Visa/Mastercard。

## 国内替代
Trae（字节跳动出品，完全免费）、通义灵码、CodeGeeX。

## 适用人群
想尝试 AI IDE 但不想立刻付费的开发者，预算有限的独立开发者。
