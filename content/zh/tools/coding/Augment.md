# Augment Code

主打代码库理解的 AI 编程助手，号称能理解你整个项目的架构和依赖关系，而不只是当前打开的文件。对于维护大型老项目的开发者来说，这个定位有吸引力。

## 核心能力
- 深度理解代码库架构和依赖
- 跨文件重构和修改建议
- 支持 VS Code 和 JetBrains
- Context engine：理解项目级别的代码关系

## 价格与访问
免费版有限额，Pro 版 30 美元/月。国内可访问但速度一般，需要外币卡。

## 国内替代
暂无直接替代，通义灵码和 CodeGeeX 更偏补全而非代码库理解。

## 适用人群
维护大型代码库的资深开发者、企业级项目团队。
