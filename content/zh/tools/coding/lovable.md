# Lovable

Lovable 是 2025 年快速走红的对话式全栈 Web 应用生成平台。输入产品需求后，它可以生成界面、业务逻辑与数据连接，并通过持续对话完成修改，适合快速验证产品想法。

## 核心能力
- 用自然语言生成可运行的 Web 应用
- 同步生成前端界面与常见后端集成
- 实时预览并通过对话迭代设计和功能
- 连接 GitHub，支持导出和继续维护代码

## 价格与访问
提供有限免费额度，付费方案约 20 美元/月起。使用额度与团队功能以官网为准。

## 适用人群
独立开发者、产品经理、设计师和需要快速制作 MVP 的创业团队。
