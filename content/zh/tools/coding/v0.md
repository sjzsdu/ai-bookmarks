# v0

Vercel 推出的 AI 前端工具，用自然语言描述你想要的界面，它直接生成可用的 React 组件（基于 shadcn/ui + Tailwind CSS）。对于前端开发者来说是 UI 搭建的加速器。

## 核心能力
- 文字描述生成 React/Next.js 组件
- 支持截图/草图转代码
- 生成的代码可以直接复制到项目
- 预览和迭代修改

## 价格与访问
免费版有生成次数限制，Pro 版 20 美元/月。国内可访问但速度一般，需要外币卡订阅。

## 国内替代
FlutterFlow（更偏移动端）、即时设计 AI（国内 UI 设计工具）。

## 适用人群
前端开发者、设计师转码、需要快速搭建 UI 原型的人。
