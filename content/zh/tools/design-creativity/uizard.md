# Uizard

AI UI 设计工具，画个手绘草图或截图，AI 自动转成可交互的界面原型。对非设计师来说是做 UI 原型的捷径，不需要学 Figma。

## 核心能力
- 手绘草图转 UI 原型
- 截图转可编辑设计
- AI 主题生成
- 拖拽式编辑器

## 价格与访问
免费版有 3 个项目，Pro 版 12 美元/月。国内可访问但速度一般。

## 国内替代
即时设计（国产 UI 设计工具）、墨刀（国产原型工具）。

## 适用人群
产品经理、非设计师、需要快速出 UI 原型验证想法的人。
