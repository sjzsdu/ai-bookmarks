remove.bg 把「抠图」这一件事做到了极致：上传图片，几秒钟返回带透明背景的成品，人像和商品边缘处理是行业标杆。功能单一但这个单点高频到值得单独付费。

## 上手体验

网页直接上传即可用；免费预览带水印，下载高清或商用需扣点数；高频使用直接接 API 更划算。

## 具体能干嘛

- 一键抠图：人像、商品、车辆等主体
- API 接入：自动化管线友好
- 批量处理：后台任务式清理图库

## 不足和坑

免费档只有小尺寸预览；头发丝、玻璃等半透明物体的边缘偶有损失；点数制对高频用户成本不低。

## 替代方案

要换背景和场景生成用 Photoroom；多工具合一看 Clipdrop；免费本地方案是 rembg。
