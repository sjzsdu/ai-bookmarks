# Obviously AI

不想写代码但想做机器学习预测？Obviously AI 就是为这种场景设计的。上传数据，选择要预测的目标，它会自动训练模型并给出结果。适合业务人员快速验证数据假设。

## 核心能力
- 自动机器学习（AutoML）
- 预测、分类、回归分析
- 自动生成模型报告
- 可以通过 API 集成到其他系统

## 价格与访问
- 免费版：有限的预测次数
- 付费版：$75/月起
- 支持信用卡付款
- 国内访问需要翻墙

## 国内替代
- AutoML 平台（阿里云）
- 百度 EasyML
- DataRobot

## 适用人群
需要做预测分析但不会写代码的业务人员和产品经理。
