Mode 是数据团队向的分析平台：以 SQL 为核心，配合 Python/R 做深度处理，分析成果一键发布成业务方可订阅的报表，在「分析自由度」和「成果运营化」之间平衡得比较好。

## 上手体验

连接数仓后建第一个 SQL 报告，参数化日期字段实现自动更新；用 Space 组织团队的分析资产。

## 具体能干嘛

- 把一份 CSV 先问出趋势和异常，再回到明细确认结论。
- 给运营周报做可复查的图表和文字说明，而不是只交一张截图。
- 用自然语言试探分析思路，确定后再把关键计算沉淀成可复用流程。

## 不足和坑

需要 SQL 能力门槛；按席位收费，观看者的席位政策要细看；可视化定制不如专业 BI 深入。

## 替代方案

拖拽式 BI 用 Tableau/Power BI；协作笔记本看 Hex/Deepnote；轻量问答用 Julius。
