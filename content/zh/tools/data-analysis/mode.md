# Mode

数据分析老手的选择。Mode 让你写 SQL 查询，然后把结果可视化成图表和仪表板。比纯 SQL 工具多了可视化功能，比 BI 工具多了代码灵活性。适合数据分析师做日常分析。

## 核心能力
- SQL + Python + R 支持
- 内置可视化图表
- 可以发布和分享分析结果
- 支持调度和自动化

## 价格与访问
- 免费版：基础功能，个人使用
- Team 版：$25/月起
- 支持信用卡付款
- 国内访问需要翻墙

## 国内替代
- 阿里 Quick BI
- 腾讯 DataManage
- DBeaver

## 适用人群
数据分析师、商业分析师，日常写 SQL 做分析的人。
