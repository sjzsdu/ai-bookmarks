Hex 是面向数据团队的协作笔记本：SQL 单元格和 Python 单元格混排，图表和交互控件直接嵌在分析里，最终发布成别人能点能看的报表，分析师的工作成果不再躺在 .ipynb 里。

## 上手体验

连接数据仓库后先跑一个 SQL 单元，结果转成 DataFrame 继续 Python 分析；发布前用布局模式整理成报表。

## 具体能干嘛

- 把一份 CSV 先问出趋势和异常，再回到明细确认结论。
- 给运营周报做可复查的图表和文字说明，而不是只交一张截图。
- 用自然语言试探分析思路，确定后再把关键计算沉淀成可复用流程。

## 不足和坑

按席位计费，团队规模要规划；复杂 Notebook 的运行环境管理有学习成本；免费档限制项目和协作者数。

## 替代方案

轻量协作看 Deepnote；BI 化发布用 Mode；本地免费方案是 Jupyter。
