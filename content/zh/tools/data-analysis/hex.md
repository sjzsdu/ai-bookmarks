# Hex

数据团队的协作工作空间。把 SQL 查询、Python 代码、可视化图表整合在一个地方，还支持 AI 帮你写代码和分析数据。适合需要写复杂查询但又想要可视化界面的数据分析师。

## 核心能力
- SQL + Python + 可视化一体化
- AI 辅助代码生成
- 实时协作
- 可以发布为交互式应用

## 价格与访问
- 免费版：基础功能
- Pro 版：$25/月
- 支持信用卡付款
- 国内访问需要翻墙

## 国内替代
- 阿里 MaxCompute
- 腾讯 CloudBase
- Jupyter Notebook

## 适用人群
数据分析师、数据工程师，需要写代码做分析的团队。
