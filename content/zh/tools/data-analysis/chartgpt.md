# ChartGPT

不想折腾 Excel 图表？ChartGPT 让你用文字描述就能生成漂亮的图表。描述你想展示什么数据，它会自动选择合适的图表类型并生成。适合需要快速做图的场景。

## 核心能力
- 自然语言生成图表
- 支持多种图表类型
- 可以上传数据或手动输入
- 导出 PNG/SVG 格式

## 价格与访问
- 免费版：有限的图表生成次数
- 付费版：$10/月
- 支持信用卡付款
- 国内访问可能需要翻墙

## 国内替代

- 百度图表
- ECharts（开源）

需要快速做图表但不想学复杂工具的运营和市场人员。
