Rows 重新想象了电子表格：单元格不只能算数，还能调用 API 抓数据（股票、天气、社媒指标）、调用 AI 分析（「总结这一列的趋势」）。分享一份表格，对方看到的是自动刷新的仪表盘。介于 Excel 和 BI 之间的新品类，轻量场景很好用。

## 核心能力
- 50+ API 集成作为表格函数
- AI 分析函数（总结、分类、提取）
- 表格一键转交互式仪表盘
- 定时自动刷新

## 价格与访问
免费档可用；付费约 15 美元/月起。需代理。

无直接对等；轻量 BI 可用伙伴云、vika。
