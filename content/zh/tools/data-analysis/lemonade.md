# Lemonade

像聊天一样探索数据。连接你的数据源后，用自然语言提问，Lemonade 会自动查询数据并给出可视化结果。比写 SQL 简单太多，适合数据分析师快速探索。

## 核心能力
- 对话式数据查询
- 自动生成图表和仪表板
- 支持多种数据源
- 可以分享分析结果

## 价格与访问
- 免费版：基础功能
- 付费版：$10/月起
- 支持信用卡付款
- 国内访问可能需要翻墙
